# salon-karte｜整体とアロマのカルテ（iPad 用）

整体とアロママッサージの両方に使える、iPad 用のカルテのアプリ（試作・第1段）。

- お客さんのデータは **iPad の中だけ**に保存する。どこにも送らない（このリポに入っているのはプログラムだけ）
- Safari で開いて「ホーム画面に追加」すると、ネットなしで動く
- 精油・成分・気をつける状態・濃度の目安は、はじめは**下書き**。アプリの中で直せる

何を作るかは `docs/設計メモ.md`、いまどこまで進んだかは `引き継ぎメモ.md`。

## iPad で開く

1. iPad の **Safari** で `https://wgackey.github.io/salon-karte/` を開く（GitHub Pages の設定がすんでいること。手順は `引き継ぎメモ.md`）
2. 画面の上（または下）の **共有ボタン（□ から ↑ が出ているしるし）** を押す
3. **「ホーム画面に追加」** → 右上の **「追加」**
4. ホーム画面にできた **「カルテ」のアイコン**から開く（いつもここから開く。Safari で開いたときとはデータの置き場がちがう）

一度ネットにつないで開けば、あとはネットなしで動く。

## ファイルの並び

| 場所 | 中身 |
|---|---|
| `index.html` `css/` `js/` | アプリ本体。組み立ての手順（ビルド）はなく、置けばそのまま動く |
| `js/db.js` | 保存（IndexedDB）と、データの形の「版」の移し替え |
| `js/seed.js` | はじめに入れる下書き（精油・成分の分類・濃度の目安など） |
| `js/logic.js` | 濃度の計算・精油の候補えらび |
| `js/views/` | 画面（ホーム・お客さん・来店・設定） |
| `sw.js` | ネットなしで動かす係。**ファイルを直したら `VERSION` と `js/version.js` を同じ数字に上げる** |
| `tests/` | テスト |

## 手元で動かす・確かめる

```
python3 -m http.server 8080      # → http://localhost:8080/
npm test                         # 計算のテストと、置く前の点検
node tests/e2e.cjs               # 画面を通しで動かすテスト（Playwright が要る。上のサーバーを動かしたまま）
```
