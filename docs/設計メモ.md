# 設計メモ｜salon-karte（整体＋アロマのカルテ）

> 2026-11-15 がっき〜と🧭司令塔で決めたこと。決まったことが変わったら、このファイルを直す。
> もとの手書きメモ3枚（顧客データベース・デザイン・アロマDB）の中身は、§3 に写してある。

## 1. 何を作るか

- 整体とアロママッサージの両方に使えるカルテ。既製品は高い・継続コストがかかる・使い勝手が合わない、が出発点
- 使うのは がっき〜（まず家族・親族・友人で使って直す）。開業の予定はまだない
- **販売も視野に入れる**（個人サロン向け・買い切り）。がっき〜専用の決め打ちは入れない

## 2. 決まったこと

| 項目 | 決定 |
|---|---|
| 動かす端末 | **iPad と iPhone の両方**（2026-11-15 追加。個人サロンは iPhone だけで始める人もいて、コストが下がる・販売の強みになる）。Safari で開いて「ホーム画面に追加」する形（PWA）。App Store には出さない。iPhone のたて持ち・片手で、来店の流れを最後まで通せること |
| 端末どうし | **同期しない**。データは端末ごとに別。iPad と iPhone のあいだは、バックアップの書き出し → 戻しで移す（戻すと入れ替わる・混ぜられない。画面にも説明を出す） |
| 保存 | **端末（iPad・iPhone）の中だけ**（IndexedDB）。ネットなしで動く。お客さんのデータは GitHub にもサーバーにも置かない |
| バックアップ | 必須の機能。ボタン1つでファイルに書き出し・戻し。合言葉でカギ。「前のバックアップから○日」を画面に出す |
| 置き場 | GitHub Pages（リポ `WGackey/salon-karte`・Public。入るのはプログラムだけ）。売るときは見えない置き方に変える |
| 人数 | 1,000人以上でも重くならない作り。一覧は名前だけ読み、カルテは開いた人の分だけ読む。人体図は「なぞった線」で保存。見本1,000人で速さを試して数字を残す |
| 予約 | アプリには「次回の予定日」→ ホームに今日・今週の予定。ネット予約は別のしくみ（LINE など）で、開業が見えてから |
| 予約の取りこみ | **A 案**：予約が Google カレンダーに入る形にして、カルテが読みに行く。日時は自動、**どのお客さんかは1タップで確かめる**（同姓同名・名前のゆれ・初めての人のため）。最初の版は日付の選択で手入力、入れ物だけ先に用意。作るのは予約のしくみを選んだあと |
| 初回の問診 | 「お客さん入力モード」。iPad を渡しても、ほかの人のカルテは見えない。戻るのは合言葉 |
| 人体図 | 前と後ろ。指でもペンでもなぞれる。色で「痛い」「こっている」などを分ける。お客さん自身もなぞれる。小さい画面では「画面いっぱい」と「上半身・下半身を大きく」でなぞりやすくする（線は図の座標で残すので、大きくしてもずれない） |
| キャリアオイル | **精油と同じ作り**（2026-11-15 追加。がっき〜：「キャリアオイルも成分で効果が変わる」）。オイルごとに成分（脂肪酸などの割合）・特徴（のび・重さ／酸化しやすさ／香り）・向いている肌の状態・向いている目的・アレルギーのしるしを持つ。問診（肌の状態・目的・アレルギー、とくにナッツ類）から、「なぜ出たか」「なぜ外したか」つきで候補を出す。手持ちから選ぶ・持っていないが合うものは下に出す・アプリの中で直せる・「下書き」と分かる・自信のない数字は空ける、も精油と同じ |
| 精油 | 基本の精油を30本ほど先に入れる。「手持ち」にチェック → その中から候補。持っていないが合うものは「次に買う候補」として下に出す |
| 施術メニュー | 入れる。メニューの一覧（名前・時間）は設定で作り、来店ごとに選ぶ（毎回変えられる・いくつも選べる） |
| 売上・料金 | **入れない**（あくまでカルテ。売上はレジアプリの役目） |
| 写真 | **入れない**（重くなる・リラクゼーション目的のカルテにする）。あとで足すなら小さくして保存 |
| ブレンドの記録 | **必須**。精油ごとの滴数・キャリアオイルの種類と量 → **濃度（％）を自動で計算**。式は **精油の量 ÷ キャリアオイルの量**（2026-11-15 決定。がっき〜が教わった「キャリアオイルの量に対して何滴入れたか」。前の「精油 ÷（キャリアオイル＋精油）」から変更）。「この量なら○滴まで」も同じ式（キャリアオイルの量 × 目安 ÷ 1滴の量）。1滴の量は設定で変えられる・はじめは 0.05ml。前回のブレンドをコピー・よく使うブレンドを名前つきで保存。キャリアオイルも一覧と「手持ち」チェック。経過のページで、ブレンド・濃度と施術後のつらさの変化を並べて見る |
| 濃度の目安 | 入れる。部位ごと（顔・体など）の上限を**使う人が設定**（決め打ちにしない・流派や資料で違うため）。超えたら色が変わって注意。妊娠中・高齢・子どもなど、お客さんの状態ごとの目安も設定できるようにする。目安はブレンドの画面にいつも出す（資料を見返さなくて済むように） |
| 部位だけのカルテ | 入れる（手だけ・足だけなど、安く受けたい需要のため）。来店ごとに「全身／部分（手・足・頭・首肩・背中 など）」を選ぶ。部分のときは、その部位の大きな図（手のひら・手の甲・足の裏・足の甲 など）に切りかわる。問診は短い版（その部位に関わる項目だけ。禁忌・アレルギーの確認は省かない）。濃度の目安も部位に合わせて切りかわる。メニューに部位をひもづけておけば、メニューを選ぶだけで図と目安がそろう |
| 反射区（足つぼの区分け） | 入れる（販売のため）。足の裏の図に重ねて「出す・出さない」を切りかえ。**はじめは出さない設定**。図は自分で描き起こす（本の図を写さない）。がっき〜は反射区を触りしか学んでいないので確かめられない → **売る前に、くわしい人か複数の資料で確かめる**。作る順番は後ろ（最初の試作には入れない） |

## 3. データの形（手書きメモから）

**お客さん（ずっと同じ・変わったら直す）**
カルテ番号（自動）・氏名・性別・生年月日（年齢は自動）・住所（郵便番号）・電話・メール・職種（営業系・事務系・工業系・主婦(夫)・学生(運動)・学生(文化)）・初回来店日・既往歴・アレルギー（押してえらぶしるし＋自由に書く欄）・避ける精油／キャリアオイル・施術歴（ほかでの経験）・自由メモ（FAX はなくす）

**来店ごと（毎回）**
来店日・生活状況・女性特有（月経・妊娠）・**肌の状態**・目的・好み（気分）・症状（タップで選ぶ＋つらさ10段階）・所見（人体図）・施術内容（整体／アロマ）・施術メニュー・使用アロマ（ブレンド：精油ごとの滴数・キャリアオイルの種類と量・濃度）・施術後経過（つらさの変化・香りの感想）・次回の予定日
施術の回数は自動で数える。

**精油のデータ（3段）**
1. 精油 × 成分の分類（アルコール類・アルデヒド類・ケトン類・フェノール類・エステル類・オキサイド類…）の割合。香りの系統で色分け（樹＝緑・花＝ピンク・柑橘＝オレンジ…）
2. 成分の分類 × 効能（冷え など）
3. 成分の分類 × 禁忌（月経・妊娠・うつ・心臓・症状）

**キャリアオイルのデータ（精油と同じ考え方）**
1. キャリアオイル × 成分（オレイン酸・リノール酸・α-リノレン酸・パルミトレイン酸・ワックスエステル…）の割合
2. 成分 × 向いている肌の状態（乾燥しやすい・べたつきやすい…）
3. オイルごと：特徴（のび・重さ／酸化しやすさ／香り）・向いている肌の状態・向いている目的・アレルギーのしるし（ナッツ類・ごま…）・気をつける状態

候補の出し方：問診の肌の状態 → 成分 → その成分が多いオイル。目的は、オイルごとの登録から。アレルギーのしるし（または欄に書いた言葉）・気をつける状態・避けるオイルにあたるものは、消さずに「理由つきで除外」。

**自動ピックアップ**：問診の症状 → 効能 → 成分の分類 → その成分が多い精油の順。禁忌・アレルギーにあたるものは**消さずに「理由つきで除外」と見せる**。最後に決めるのは施術する人。

## 4. 導線（1回の来店）

0. ホーム：今日・今週の予定／名前で探す／新しく登録
1. お客さんのページ：上に注意のしるし（妊娠中・アレルギー・既往歴）と前回の経過。下に来店の一覧（タブではなく日付の一覧）
2. 問診：前回の中身が入った状態で開き、変わったところだけ直す
3. 所見：人体図
4. 精油の候補：「なぜ出たか」「なぜ外したか」つき。香りの系統で絞ってお客さんと選ぶ
5. 施術内容
6. 施術後：経過・つらさの変化・香りの感想 → 保存

ほかに「経過のページ」：症状のつらさと使った精油を回ごとに並べて見る。

## 5. 気をつけること

- 精油の成分・効能・禁忌は、司令塔側で一般的な内容の下書きを作る。**がっき〜が自分の資料で確かめて直す前提**（アプリの中で直せる）。資料は探し中
- 売る版：教科書の表をそのまま使わない（著作権）。「〇〇に効く」と医療のように書かない。データは入れ替えやすい形に
- 売る版：サロン名・施術メニューは買った人が設定できる
- 売る前に整理すること：サポートの手間・税金（副業の収入・扶養）・Google カレンダー連携の審査
