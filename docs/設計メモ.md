# 設計メモ｜salon-karte（整体＋アロマのカルテ）

> 2026-11-15 がっき〜と🧭司令塔で決めたこと。決まったことが変わったら、このファイルを直す。
> もとの手書きメモ3枚（顧客データベース・デザイン・アロマDB）の中身は、§3 に写してある。

## 1. 何を作るか

- 整体とアロママッサージの両方に使えるカルテ。既製品は高い・継続コストがかかる・使い勝手が合わない、が出発点
- 使うのは がっき〜（まず家族・親族・友人で使って直す）。開業の予定はまだない
- **販売も視野に入れる**（個人サロン向け・買い切り）。がっき〜専用の決め打ちは入れない

## 2. 決まったこと

| 項目 | 決定 |
|---|---|
| 動かす端末 | **iPad と iPhone の両方**（2026-11-15 追加。個人サロンは iPhone だけで始める人もいて、コストが下がる・販売の強みになる）。Safari で開いて「ホーム画面に追加」する形（PWA）。App Store には出さない。iPhone のたて持ち・片手で、来店の流れを最後まで通せること |

| 保存のしかた | カルテ（来店の流れ）は**自動で保存**（施術の合間に消えないほうが大事）。「保存済み」が見えるようにし、最後のボタンは「できた（とじる）」と呼ぶ（2026-11-15） |
| バックアップ | 必須の機能。ボタン1つでファイルに書き出し・戻し。合言葉でカギ。「前のバックアップから○日」を画面に出す。**Safari のタブで使っていると、Safari のデータの消去で消える／ホーム画面のアイコンを消すと消える**（下の「実機で確かめたこと」） → はじめの案内とバックアップの画面に「消去する前に、かならずバックアップ」と出す。「消されにくい保存」を開くたびに頼み、効いているかをバックアップの画面に出す（0.12.0）。**バックアップの知らせ（2026-11-16 がっき〜決定・0.13.0 で作った）**：ネットにデータを置く方式（Firebase など・全自動）は**やらない**（売る場合もリスクを避ける・個人情報を外に置かない決まりはそのまま）。作るのは **A＋B のセット**：A＝知らせを強くする（カルテを閉じるとき＋ホームに「○日バックアップしていない」を目立たせる）／B＝その知らせから1タップで書き出し → 共有の画面 →「ファイル」アプリ（iCloud Drive など）に保存（Safari の決まりで、最後の保存のタップは残る）。あわせて「ホーム画面に追加して使ってね」の案内を入れる（Safari は7日ほど開かないサイトのデータを消すことがあるため）。日数・言葉はおまかせ（下の「バックアップの知らせの細かいところ」） |
| 置き場 | GitHub Pages（リポ `WGackey/salon-karte`・Public。入るのはプログラムだけ）。売るときは見えない置き方に変える |
| 人数 | 1,000人以上でも重くならない作り。一覧は名前だけ読み、カルテは開いた人の分だけ読む。人体図は「なぞった線」で保存。見本1,000人で速さを試して数字を残す |
| 予約 | アプリには「次回の予定日」（時間も入れられる）→ ホームに今日・今週・その先の予定と、予定日を過ぎて来店の記録がない人（0.7.0）。予定を押すとその人のカルテ。ネット予約は別のしくみ（LINE など）で、開業が見えてから |
| 予約の取りこみ | **先送り・入れ物だけ**（2026-11-15 がっき〜：現状は要らない）。やるときは **A 案**：予約が Google カレンダーに入る形にして、カルテが読みに行く。日時は自動、**どのお客さんかは1タップで確かめる**（同姓同名・名前のゆれ・初めての人のため）。最初の版は日付の選択で手入力、入れ物だけ先に用意（0.7.0：予定の入れ物 `appts`。お客さんが決まっていない予定は「お客さんを確かめる」と出る）。作るのは予約のしくみを選んだあと |
| お客さんが書く／施術する人が書く | **来店の流れを2つに分ける**（2026-11-15 がっき〜の指摘：「お客さんが入力するターンと施術者が入力するターンが分からない」）。**前半＝お客さんから聞くこと**（お客さんの情報・同意書とサイン・問診・気になるところの図）／**後半＝施術者の記録**（所見・オイル・ブレンド・施術・施術後）。色で分ける（前半＝橙、後半＝緑）。いまどちらかを、帯でいつも見せる |
| お客さん用の画面 | 「お客さんに渡す」を押すと切りかわる。字とボタンを大きく・やさしい言葉・1画面に少しずつ。**ほかのお客さんのカルテ・後半の画面・設定には行けない**（アドレスを打ちかえても・戻るボタンでも・開き直しても）。書き終わると「ありがとうございました。スタッフにお返しください」。戻るのは合言葉（数字4けた・設定で決める）。合言葉を忘れたときの抜け道は作らない（カギの穴になるため。バックアップから戻す） |
| 初回・2回目から | 初回は、お客さんの情報（氏名・連絡先・既往歴・アレルギー・生活の様子）もお客さん自身が書ける。2回目からは、施術する人が聞きながら書くのを基本にして、「お客さんに渡す」も選べる（どちらを大きく出すかは設定で変えられる。がっき〜の返事待ち） |
| 人体図 | 前と後ろ。指でもペンでもなぞれる。色で「痛い」「こっている」などを分ける。**図は2つ**（2026-11-15 がっき〜決定）：お客さんがなぞる「気になるところ」（つぶつぶの線）と、施術する人がなぞる「所見」（ぬった線）。別々に残し、重ねて見られる（片方だけ・両方を切りかえ）。「これまでの記録」でも、どちらの図か分かる。**画面いっぱいのときは、上の左に、はっきりした「もどる（とじる）」**（がっき〜：「閉じ方が分かりづらい。上のほうに戻るボタンを」）。道具は見出しで分ける（症状（色）／ペンの太さ／直す／見え方）。「ひとつ戻す」は直前の1手（消しゴムで消したことも含む）を取り消す、「消しゴム」はさわった線だけ消す（2026-11-15 がっき〜が実機で触った感想から）。小さい画面では「画面いっぱい」と「上半身・下半身を大きく」でなぞりやすくする（線は図の座標で残すので、大きくしてもずれない） |
| 図の書き方（0.9.0） | **書くときは、いつも画面いっぱい**（2026-11-15 がっき〜：「画面いっぱいと標準の2つは要らない。どちらかに統一」）。来店の流れの中には小さな図（見るだけ・この上ではなぞれない）を置き、押すと画面いっぱいで開いて書ける（「✎ 押すと画面いっぱいで書けます」）。気になるところ・所見・部位の図・お客さん用の画面、ぜんぶ同じ。上の「‹ もどる（とじる）」はそのまま |
| だれが書いたか（0.11.0 で見直し） | **細かく分けない**（2026-11-16 がっき〜：「お客様の所見と施術者の所見の2通りだけで良い。自分じゃ書けない人もいる」）。図は「気になるところ（お客さんの所見）」と「所見（施術者）」の2つだけ。聞きながら施術する人が書いても「お客さんの所見」。0.9.0 の「書いた人」の帯・らんごとの印・線ごとの札・お客さんが書いた回は見るだけ（lock）は、画面から外した（入っているデータは消さない）。**お客さんも施術する人も、まちがえた線・しるしを消しゴム・戻すで消せる**（がっき〜：「私でもまちがってタッチすることが多い」） |
| 図の形（0.11.0） | 手は関節で分けずシンプルに・足の甲もシンプルに・首肩（後ろ）と背中の肩の線と肩甲骨を直した。**りんかくの位置は変えない直し方**（前の来店の線がずれない）。りんかくそのものを変えるときは、来店に図の形の版を持たせる。確かめ用の画像は `docs/zu-kakunin/`。**0.12.0**：背中・腰の図の腰を 全身（後ろ）と同じ描き方に・頭（前・後ろ）の肩の線も同じ直し（どちらも中の線だけ） |
| キャリアオイル | **精油と同じ作り**（2026-11-15 追加。がっき〜：「キャリアオイルも成分で効果が変わる」）。オイルごとに成分（脂肪酸などの割合）・特徴（のび・重さ／酸化しやすさ／香り）・向いている肌の状態・向いている目的・アレルギーのしるしを持つ。問診（肌の状態・目的・アレルギー、とくにナッツ類）から、「なぜ出たか」「なぜ外したか」つきで候補を出す。手持ちから選ぶ・持っていないが合うものは下に出す・アプリの中で直せる・「下書き」と分かる・自信のない数字は空ける、も精油と同じ |
| 精油 | 基本の精油を30本ほど先に入れる。**はじめの一覧は、精油もキャリアオイルも資料にあるものだけ**（2026-11-16 がっき〜：「自分で増やしたり減らしたりできるから、最初は資料にあるものだけでよい」。0.12.0）。「手持ち」にチェック → その中から候補。持っていないが合うものは「次に買う候補」として下に出す |
| 施術メニュー | 入れる。メニューの一覧（名前・時間）は設定で作り、来店ごとに選ぶ（毎回変えられる・いくつも選べる） |
| 売上・料金 | **入れない**（あくまでカルテ。売上はレジアプリの役目） |
| 写真 | **入れない**（重くなる・リラクゼーション目的のカルテにする）。あとで足すなら小さくして保存 |
| ブレンドの記録 | **必須**。精油ごとの滴数・キャリアオイルの種類と量 → **濃度（％）を自動で計算**。式は **精油の量 ÷ キャリアオイルの量**（2026-11-15 決定。がっき〜が教わった「キャリアオイルの量に対して何滴入れたか」。前の「精油 ÷（キャリアオイル＋精油）」から変更）。「この量なら○滴まで」も同じ式（キャリアオイルの量 × 目安 ÷ 1滴の量）。1滴の量は設定で変えられる・はじめは 0.05ml。前回のブレンドをコピー・よく使うブレンドを名前つきで保存。キャリアオイルも一覧と「手持ち」チェック。経過のページで、ブレンド・濃度と施術後のつらさの変化を並べて見る |
| 濃度の目安 | 入れる。部位ごと（顔・体など）の上限を**使う人が設定**（決め打ちにしない・流派や資料で違うため）。超えたら色が変わって注意。妊娠中・高齢・子どもなど、お客さんの状態ごとの目安も設定できるようにする。目安はブレンドの画面にいつも出す（資料を見返さなくて済むように） |
| 濃度の目安の数字（0.10.0・0.11.0） | がっき〜の資料に合わせた：**体 5％・顔 3％・部分ぬり（気になるところに少し）10％**（精油 ÷ キャリアオイル）。**手・足だけのトリートメントは体と同じ 5％**（2026-11-16 がっき〜）。**はじめての人の目安**（2026-11-16 がっき〜が決めた）：**体 1％・顔 0.5％・手・足 1％**。**来店が1回目なら、ブレンドの画面ではじめからこちらで色が変わる**。施術する人が1タップでふつうの目安と切りかえられる。子ども・高齢・妊娠中は資料に数字がないので空き。敏感肌は「うすめに」（数字なし）と画面に出す。直した数字は版を上げても上書きしない。体 5％・顔 3％・部分ぬり 10％ は がっき〜が「そのまま」と決めたので「下書き」のしるしは付けない（0.12.0） |
| 部位だけのカルテ | 入れる（手だけ・足だけなど、安く受けたい需要のため）。来店ごとに「全身／部分（手・足・頭・首肩・背中 など）」を選ぶ。部分のときは、その部位の大きな図（手のひら・手の甲・足の裏・足の甲 など）に切りかわる。問診は短い版（その部位に関わる項目だけ。禁忌・アレルギーの確認は省かない）。濃度の目安も部位に合わせて切りかわる。メニューに部位をひもづけておけば、メニューを選ぶだけで図と目安がそろう。**0.7.0 で入った**：部位は 手・足・頭・首・肩・背中・腰（いくつでも選べる）。毎回 全身から始まる。「これまでの記録」の図は押すと大きく見られる |
| 反射区（足つぼの区分け） | 入れた（0.8.0・販売のため）。施術する人の「所見」の足の裏の図に重ねて「出す・出さない」を切りかえ。**はじめは出さない**。図は自分で描き起こした大まかな区分け10個（本の図を写さない）。**「下書き・確かめていません」と画面に出す**。名前・色・出す出さないは使う人が直せる。「〇〇に効く」とは書かない。がっき〜は反射区を触りしか学んでいないので確かめられない → **売る前に、くわしい人か複数の資料で確かめる**。位置に自信のない区分けは入れていない |
| 売るための設定 | お店の名前・施術する人の名前を設定できる（ホーム・お客さん用の画面・同意の記録・バックアップのファイル名）。**はじめて開いたときの案内**（名前 → 合言葉 → 手持ちの精油・キャリアオイル → メニュー → 下書きの確かめ → バックアップ。とばせる・設定からもう一度）。「この考え方で作っています」と「使い方の手引き」はアプリの中で読める（ネットなし）。売り方そのもの（値段・置き場・使える人をしぼるしくみ）はまだ作らない |
| 新しい版への切りかえ | **アプリを閉じなくても気づける**（2026-11-15 がっき〜の指摘）。前に戻ってきたとき・開いたままでも数時間に1回・ホームで下に引っぱったとき・設定のボタンで、新しい版をさがす。**切りかえるのは使う人が押したときだけ**。来店の途中は小さなしるし、お客さん用の画面では出さない。ネットなしのときは だまって何もしない |

### バックアップの知らせの細かいところ（0.13.0 で作った・🛠️が決めた。がっき〜が触って直す）
| 項目 | 決め |
|---|---|
| 毎日バックアップ（2026-11-16 がっき〜決定・0.13.1） | 仕事で使うので**毎日**。ただし**前のバックアップのあとに記録や設定が変わったときだけ**知らせる（何も変えていない日は出さない＝うるさくしない）。0.13.0 の「7日・30日」はやめた |
| ホームの知らせ | 前のバックアップのあとに変わったものがあれば、ホームのいちばん上（検索のらんの上）に橙の帯「**最後のバックアップ：11月15日（日）（2日前）・そのあと お客さん3人分の記録が変わっています**」＋ボタン「いまバックアップ」（0.14.0）。人数＝そのあとカルテ・お客さんの情報を書いた・消した人の数（`meta` の `changedPeople`。バックアップすると空に）。お客さんは変わらず設定だけなら「そのあと 設定などが変わっています」。3日以上たったら赤。まだ一度もしていない人は、お客さんが1人以上いれば赤。**変わっていなければ上には出さない**（いちばん下の小さな「前のバックアップから○日」だけ） |
| カルテを閉じるとき | **聞かない**（0.14.0・2026-11-17 がっき〜：閉じるたびは多い。お客さんごとにする人も、1日の終わりにまとめてする人もいる）。0.13.0〜0.13.1 の「バックアップしますか？（いまする／あとで）」はやめた。知らせはホームのいちばん上だけ |
| 1タップで書き出し | 知らせのボタンから、そのまま共有の画面を出す。合言葉つきのバックアップは「作る」と「共有」が2回押しになる（共有の画面は押したその場でしか出せない）→ 合言葉は**設定で決めた「バックアップの合言葉」を端末に覚えさせない**かわりに、知らせからの書き出しは「合言葉を入れる → 保存先をえらぶ」の2回。合言葉なしで書き出す人は1回 |
| ホーム画面に追加の案内 | Safari のタブで開いているとき（ホーム画面のアイコンからではないとき）だけ、ホームに「ホーム画面に追加して使ってね（Safari のタブだけだと、7日ほど開かないとデータが消えることがあります）」＋やり方。閉じられる・閉じたら 30日出さない |
| 合言葉の覚え方 | 合言葉そのものは端末に覚えさせない。覚えるのは「前に合言葉をつけたか（つけた／つけない）」だけ。つけない人は、知らせを出すときに中身を先に作っておき、ボタン1回で共有の画面。はじめての人・つける人は小さなパネル（合言葉を入れる → 保存先をえらぶ） |
| ホーム画面に追加の案内（言葉） | 「タブで使うと、7日ほど開かないときや Safari の消去で消えることがある・アイコンから開けば消去しても消えない」＋やり方3行。お客さんが入っているときは「**いまタブに入っているデータは、アイコンの方には入らない（置き場が別）。バックアップで書き出して、アイコンから開いて戻す**」も出す。iPad・iPhone のときだけ出す（やり方が Safari のものなので） |
| 言葉 | 事実に合わせる（下の「実機で確かめたこと」）。専門用語を使わない |

**実機で確かめたこと（2026-11-16 がっき〜の iPad）**
| 試したこと | 結果 |
|---|---|
| ホーム画面のアイコンから開いたカルテ →「設定 → Safari → 履歴と Web サイトデータを消去」 | **消えなかった** |
| ホーム画面の**アイコンを消す** | **データも消えた** |
| 「履歴と Web サイトデータを消去」のあと、**Safari のタブ**で開く | **消えていた**（タブとホーム画面のアプリは、データの置き場が別） |

→ ホーム画面に追加して使う形なら、Safari の消去では消えない。ただし**アイコンを消すと消える**ので、消す前にバックアップ。タブで入れたデータはアイコンの方には出てこない（移すならバックアップの書き出し → 戻し）。「7日ほど開かないと消える」件は実機で試せないので、バックアップの知らせで守る。画面の注意（`SAFARI_WARN`）・「ホーム画面に追加」の案内・手引きの言葉をこの結果に合わせた（0.13.0。1台・1回の試しなので「消去の前にもバックアップ」は残す）

## 3. データの形（手書きメモから）

**同意書と注意事項（2026-11-15 がっき〜決定）**：お客さんに端末で読んでもらい、指（ペン）でサイン。サインは線のデータで、日付・同意したときの文・文の版といっしょに残す。文は設定で直せる（はじめは自分の言葉の下書き。法律の文書として正しいかは保証しない）。サインは、お客さん用の画面の中で書いてもらう（ほかのお客さんの情報は出ない・合言葉がないと出られない）

**生活の様子（2026-11-15 がっき〜決定）**：睡眠・食事・お通じ・運動・たばこ・お酒・お菓子。初回に聞いて、変わったときに直す。毎回の問診には出さない（お客さんの情報から直す）

**触れてほしくない部位（2026-11-15 がっき〜決定）**：からだの図に「×」のしるし。お客さんの側でつけられて、施術する人も足せる。次の来店にも写り、施術の前（施術の画面・来店の上の帯・お客さんのページ）に目に入る

**精油のデータ（3段）**（2026-11-15 がっき〜の資料「アロマDB」「アロマテラピーカルテ」に合わせた。版 0.5.0）
1. 精油 × 成分の分類の割合。分類は資料の7つ（炭化水素類・アルコール類・アルデヒド類・ケトン類・フェノール類・エステル類・オキシド類）。資料に割合がないところは「入っている（割合は分からない）」で、数字を埋めない。分類の中の**成分（小分類：リナロール・カンファー など）**も、どの精油に入っているかを持つ
2. 成分 × 作用（働き）。資料の作用の名前を、ふだんの言葉の18のまとまりに分けて持つ（資料での呼び方も残す）。精油ごとの「効能」のらんも持つ
3. 成分の分類 × 気をつける状態（ケトン類：乳児・妊娠・てんかん・血圧の薬。フェノール類：かならずうすめる・敏感肌は⚠）。精油ごとの NG（使わない）と「⚠ だけ」、OK（向いている状態・場面）、植物アレルギー・科も持つ
- 香りの系統は資料の3つ：**樹木系＝緑・花穂系＝ピンク・柑橘系＝オレンジ**。どの精油がどれかも資料のとおり
- 精油は資料の30本。前の下書きにだけあった11本は、0.12.0 で消した（使っている端末でもぜんぶ消す。がっき〜が自分で足したものは残す。過去の来店のブレンドは名前と量を持っているので、そのまま読める）

**キャリアオイルのデータ（精油と同じ考え方）**
1. キャリアオイル × 成分（オレイン酸・リノール酸・α-リノレン酸・パルミトレイン酸・ワックスエステル…）の割合
2. 成分 × 向いている肌の状態（乾燥しやすい・べたつきやすい…）
3. オイルごと：特徴（のび・重さ／酸化しやすさ／香り）・向いている肌の状態・向いている目的・アレルギーのしるし（ナッツ類・ごま…）・気をつける状態

候補の出し方：問診の肌の状態 → 成分 → その成分が多いオイル。目的は、オイルごとの登録から。アレルギーのしるし（または欄に書いた言葉）・気をつける状態・避けるオイルにあたるものは、消さずに「理由つきで除外」。

**自動ピックアップ**：資料の3段のとおり、**つらいところ → 作用 → 成分（分類・小分類）→ 精油**。つらいところ → 作用 には重み（なし・少し・とても。がっき〜のメモ「重みに差をつけたほうがいい」）。資料の「OK」・使いどころも点に足し、「なぜ出たか」に出す。禁忌・アレルギーにあたるものは**消さずに「理由つきで除外」と見せる**（資料の「希釈でOK」「注意」は外さずに ⚠）。妊娠の時期は月数から、乳幼児・子ども・高齢は生年月日から自動（**乳幼児＝0〜6歳／子ども＝7〜17歳（乳幼児とは重ねない・18歳から大人）／高齢者＝60歳以上**。2026-11-16 がっき〜が決めた・はじめから入れておく・設定で直せる）。分からないときは安全側。最後に決めるのは施術する人。
